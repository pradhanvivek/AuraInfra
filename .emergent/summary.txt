<product_requirements>
The AuraInfra.ai app is a personal asset management system, initially focused on properties, now expanded to include vehicles, appliances, and jewelry, with new additions for furniture and art. It provides property listing, detailed views (documents, fixtures, health score, Vastu, AI floor plans, paint estimation), user profiles with avatar/preferences, and notifications. Core features include a dashboard with tile-based navigation, CRUD operations for assets (manual and AI-powered data entry), warranty tracking, and a portfolio dashboard for total asset value with PDF export. Recent improvements fixed dark mode, login navigation, dynamic currency display, full-screen image viewing/sharing, AI receipt scanning (Indian receipts supported), avatar uploads, and robust backend/frontend communication. The system also now includes a quick asset scan and an admin dashboard for user statistics.
